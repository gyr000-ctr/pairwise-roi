# pairwise-roi

## 题面（可直接粘贴）

支持只对图像指定区域做重采样，并保证内存与并发约束。约束：区域结果与整图裁剪后重采样一致到 1e-12；越界与空区域要给出可区分的错误；不得为局部复制整图，2000x2000 图峰值内存不超过整图 1.2 倍；同一 Resizer 并发调用结果与串行一致；不带区域的旧调用输出逐字节不变。验收：python -m pytest tests -q -k roi。改动限 2 到 3 个文件，增量构建加测试不超过 30 秒。不得改动既有测试与既有行为。交付给命令、输出、耗时三行自测证据。

## 边界要求（评审侧隐藏用例判分，不在可见测试里）

- 空图像要报错
- 非方形区域
- 超大图不得复制整图
- 旧接口逐字节不变
- 并发调用安全

## 运行方式

```bash
python -m pytest tests -q
```

初始 15 failed。可见测试只覆盖主功能（3 分线），通过不代表满分。
